# FoodieFrenzy Frontend

This is the frontend for the FoodieFrenzy application, a modern grocery ordering platform.

## Latest Update

Fixed image loading issues with Cloudinary integration. Images should now load properly from the backend.

## Features

- Browse menu items with images
- Add items to cart
- Checkout process
- Order history
- Responsive design

## Technologies

- React
- Vite
- Tailwind CSS
- Axios for API requests
